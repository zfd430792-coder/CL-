# EXIF-бот для Telegram

Присылаешь боту фото файлом, а он показывает, что о нём можно узнать по метаданным: где и когда оно сделано, на какое устройство, кто автор. Внутри работает [ExifTool](https://exiftool.org), бот лишь выбирает из его вывода самое важное.

## Как выглядит ответ

```
🔴 В файле есть координаты места съёмки
Тегов метаданных в файле: 45

📍 Где снято
55.752089, 37.615633 (точность ±5 м)
Высота: 152 м над уровнем моря
Камера смотрела на юго-запад (226°)
Google Карты · Яндекс Карты

🕐 Когда
15.09.2026 в 18:42:07 (UTC+03:00)

📱 Устройство
Apple iPhone 13
Объектив: iPhone 13 back dual wide camera 5.1mm f/1.6
ПО: 17.5.1

📷 Параметры съёмки
1/120 с · f/1.6 · ISO 50 · 5.1 мм (эквивалент 26 мм)

🗂 Файл
JPEG · 1600×1200 · 43 КБ
```

Если в фото есть координаты, следом бот присылает точку на карте. Если фото отправить обычным способом (со сжатием), бот покажет, что Telegram уже вырезал метаданные.

Файлы нигде не сохраняются: бот скачивает фото в память, передаёт его ExifTool и сразу забывает.

## Установка на сервер одной командой

Подойдёт VPS с Ubuntu 22.04+ или Debian 12+. Сначала создай бота в [@BotFather](https://t.me/BotFather) (`/newbot`) и получи токен. Потом зайди на сервер по SSH и выполни:

```bash
curl -fsSL https://raw.githubusercontent.com/zfd430792-coder/CL-/HEAD/install.sh | sudo bash
```

Скрипт поставит Python и ExifTool, скачает бота в `/opt/exif-bot` и спросит токен. Потом предложит написать боту любое сообщение: так бот запомнит тебя и будет отвечать только тебе (этот шаг можно пропустить клавишей Enter). В конце бот запускается как служба: работает в фоне и сам поднимается после перезагрузки сервера.

Чтобы обновить бота, выполни ту же команду ещё раз. Токен и настройки сохранятся.

Управление:

- `journalctl -u exif-bot -f`: логи
- `systemctl restart exif-bot`: перезапуск
- `systemctl stop exif-bot`: остановка
- `/opt/exif-bot/.env`: токен и список ID; после правки перезапусти бота

Если зашёл на сервер сразу под root и команды `sudo` нет, выполни то же самое без `sudo`. Если нет `curl`, сначала поставь его: `apt install -y curl`.

## Запуск на своём компьютере

### 1. Создай бота и получи токен

В Telegram открой [@BotFather](https://t.me/BotFather), отправь `/newbot`, придумай имя и username (он должен заканчиваться на `bot`). BotFather пришлёт токен вида `123456789:AAH...`. Это пароль от бота, никому его не показывай.

### 2. Установи ExifTool

- **Windows:** скачай Windows Executable с [exiftool.org](https://exiftool.org) и распакуй архив. Переименуй `exiftool(-k).exe` в `exiftool.exe` и положи рядом с `bot.py`. Если в архиве есть папка `exiftool_files`, её тоже.
- **macOS:** `brew install exiftool` или установщик `.pkg` с exiftool.org.
- **Linux (Ubuntu/Debian):** `sudo apt install libimage-exiftool-perl`.

### 3. Установи Python и зависимости

Нужен Python 3.10 или новее ([python.org](https://www.python.org/downloads/); на Windows при установке отметь «Add Python to PATH»). В папке с ботом:

```bash
python -m venv .venv

# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

### 4. Впиши токен

Скопируй файл `.env.example` в `.env` и вставь токен:

```
BOT_TOKEN=123456789:AAH...
```

Файл `.env` указан в `.gitignore`, поэтому в git он не попадёт.

### 5. Запусти

```bash
python bot.py
```

Когда в консоли появится `Start polling`, бот работает. Он отвечает, пока открыто это окно. Напиши ему `/start`.

## Как отправить фото без сжатия

- **Телефон:** 📎 → Файл → выбери фото из галереи.
- **Telegram Desktop:** перетащи фото в чат и сними галочку «Сжать изображение».

## Закрыть бота от чужих

Установщик для сервера делает это сам. При запуске на компьютере бот по умолчанию отвечает всем, кто его найдёт, и прогоняет через ExifTool любые присланные файлы. Если бот нужен только тебе:

1. Отправь боту `/id`, он пришлёт твой Telegram ID.
2. Впиши ID в `.env`: `ALLOWED_USERS=123456789` (несколько ID через запятую).
3. Перезапусти бота. Остальным он отвечать перестанет.

ExifTool тоже стоит держать свежим: в старых версиях были опасные уязвимости (например, CVE-2021-22204).

## Если что-то не так

- **«Не найден ExifTool»**: ExifTool не установлен или бот его не видит. Путь можно указать в `.env`, например `EXIFTOOL=C:\tools\exiftool.exe`.
- **Нет координат:** в настройках камеры выключено сохранение местоположения, или фото отправлено со сжатием. На Android система ещё может скрывать геолокацию от приложений без нужного разрешения, и тогда до бота она не доходит.
- **«Файл больше 20 МБ»**: Telegram не даёт ботам скачивать файлы крупнее.
- **В логах `Conflict: terminated by other getUpdates request`**: бот с этим токеном запущен где-то ещё, например и на сервере, и на компьютере. Telegram отдаёт сообщения только одной копии, вторую нужно остановить.

## Что внутри

- `bot.py`: Telegram-часть (команды, приём файлов, ответы), на [aiogram 3](https://docs.aiogram.dev).
- `exif_report.py`: запуск ExifTool и сборка отчёта из его JSON-вывода.
- `install.sh`: установка на сервер одной командой (systemd-служба от отдельного пользователя без прав).
